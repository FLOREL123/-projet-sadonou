# 📘 Guide d'Utilisation - Carte de Membre SADONOU

**Version** : 1.0  
**Date** : 2026-09-01  
**Association** : Alladaxónou Houègbonou SADONOU

---

## 🎯 Vue d'Ensemble

La **Carte de Membre SADONOU** est un système automatisé qui permet à chaque adhérent de générer et télécharger sa carte numérique une fois que son profil est suffisamment complété.

**Condition** : Le profil doit être complété à **minimum 80%** pour déverrouiller la carte.

---

## 🚀 Guide Pas à Pas pour l'Utilisateur

### Étape 1 : Se Connecter au Profil

1. Aller sur la page d'accueil : **Association SADONOU**
2. Cliquer sur **"Rejoindre le répertoire"**
3. Remplir le formulaire d'inscription (8 champs minimum)
4. Cliquer sur **"Créer mon compte →"**
5. Cliquer sur **"Compléter mon profil →"**

**Résultat** : Vous êtes redirigé vers votre **Page Profil**

---

### Étape 2 : Compléter le Profil

Sur la **Page Profil**, vous verrez :

#### Section 1 : Alerte de Profil Incomplet
- **Badge** : "Profil incomplet"
- **Pourcentage** : "X% complété" (ex: 17%)
- **Champs manquants** : liste des champs à remplir
- **Barre de progression** : indicateur visuel

#### Section 2 : Informations du Profil

**MON PROFIL** (Colonne gauche)
- Salutation personnalisée
- Bouton "Modifier"
- Liste des champs manquants

**PROFIL** (Colonne droite)
- Pourcentage de complétion
- Bouton "Compléter mon profil"
- **Section CARTE DE MEMBRE** (voir ci-dessous)

---

### Étape 3 : Remplir les Champs Requis

Cliquez sur **"Compléter mon profil"** pour ouvrir le formulaire.

**4 Sections à compléter** :

#### 👤 Identité (5 champs)
- Prénom *(pré-rempli, non modifiable)*
- Nom *(pré-rempli, non modifiable)*
- **Sexe*** - Sélectionner Masculin ou Féminin
- **Date de naissance*** - Format JJ/MM/AAAA
- **Nationalité*** - Ex: Béninoise
- N° Matricule *(auto-généré, non modifiable)*
- Email *(email d'inscription, non modifiable)*

#### 📞 Contact (4 champs requis)
- Téléphone / Contact
- **Ville de résidence*** - Ex: Cotonou
- **Pays de résidence*** - Ex: Bénin
- **Adresse complète*** - Adresse physique

#### 🤝 Vie Amicale & Observations (7 champs requis)
- **Date d'adhésion amicale*** - Quand avez-vous adhéré?
- **Statut du membre*** - Actif / Inactif / Suspendu / Fondateur
- **Situation de cotisation*** - À jour / En retard / Exonéré
- **Poste à l'amicale*** - Votre rôle (Président, Trésorier, etc.)
- **Disponibilité bénévolat*** - Très disponible / Disponible / Peu disponible / Non disponible
- **Compétences particulières*** - Vos domaines de compétence
- **Contribution possible*** - Comment pouvez-vous aider l'association?
- **Besoins / Attentes*** - Vos attentes par rapport à l'association

#### 📸 Photo (Optionnel)
- Upload d'une photo de profil (JPG, PNG - max 5MB)
- Affichée sur la carte de membre

**Note** : Les champs marqués avec * sont **obligatoires**

---

### Étape 4 : Vérifier la Progression

Pendant que vous remplissez les champs :
- La **barre de progression** se met à jour en temps réel
- Les **champs manquants** disparaissent de la liste
- Le **pourcentage** augmente

---

### Étape 5 : Enregistrer votre Profil

1. Remplissez **tous les champs requis** (marqués avec *)
2. Cliquez sur **"Enregistrer les modifications"**
3. Une alerte confirmera : **"✓ Profil mis à jour avec succès!"**

**Résultat** : Le formulaire se ferme et la page se met à jour

---

### Étape 6 : Débloquer votre Carte de Membre

#### Cas A : Profil < 80%
Si votre profil est encore incomplet (< 80%) :

**Section "Carte de Membre"** affichera :
- ⏳ **Message** : "Complétez votre profil à 80% pour débloquer votre carte de membre."
- **Matricule** : Votre numéro unique (SADNOW-XXXX-XXXX)
- **Progression** : "X% (minimum 80% requis)"

**Action** : Continuez à remplir les champs manquants jusqu'à 80%+

---

#### Cas B : Profil >= 80%
Une fois votre profil à **80% ou plus** :

**Section "Carte de Membre" se déverrouille** et affiche :

```
┌─────────────────────────────────────────┐
│          SADONOU (en vert)              │
│   Association Alladaxónou Houègbonou    │
│                                         │
│  [Photo]  NOM Prénom                    │
│           Matricule: SADNOW-2026-0001   │
│           Âge: 46 ans                   │
│           Nationalité: Béninoise        │
│                                         │
│      Carte valide - SADONOU             │
└─────────────────────────────────────────┘

    📥 Télécharger ma carte PDF
```

---

### Étape 7 : Télécharger votre Carte en PDF

1. Cliquez sur le bouton **"📥 Télécharger ma carte PDF"**
2. Une **fenêtre d'impression** s'ouvrira
3. **Options d'impression** :
   - ✅ **Imprimer sur papier** : Impression physique couleur
   - ✅ **Enregistrer en PDF** : Fichier numérique sur votre ordinateur
   - ✅ **Partager** : Envoyer à quelqu'un d'autre

4. **Dimensions recommandées** :
   - Format : Paysage (horizontal)
   - Papier : A4 standard
   - Couleur : Obligatoire (pour le dégradé vert)
   - Qualité : Haute résolution

5. Cliquez **"Imprimer"** ou **"Enregistrer"**

**Résultat** : Votre carte est maintenant disponible à utiliser!

## 🔐 Conditions de Déverrouillage

### Seuil: 80% de Complétion

**Sur 14 champs requis** :
- ✅ **11 champs** = 78% → Verrouillée (pas assez)
- ✅ **12 champs** = 86% → **Déverrouillée** ✓
- ✅ **14 champs** = 100% → **Complètement déverrouillée** ✓

### Les 14 Champs Requis:
1. Sexe
2. Date de naissance
3. Nationalité
4. Ville de résidence
5. Pays de résidence
6. Adresse complète
7. Date d'adhésion amicale
8. Statut du membre
9. Situation de cotisation
10. Poste à l'amicale
11. Disponibilité bénévolat
12. Compétences particulières
13. Contribution possible
14. Besoins / Attentes

**Champs non-requis** (ne comptent pas dans le %) :
- Téléphone (optionnel)
- Photo (optionnelle)

## ⚙️ Format de Matricule

### Structure: `SADNOW-YYYY-XXXX`

Exemple : `SADNOW-2026-0001`

- **SADNOW** : Code de l'Association
- **2026** : Année de création du compte
- **0001** : Numéro séquentiel (généré aléatoirement)

**Important** :
- Chaque adhérent a un matricule **unique**
- Le matricule ne change **jamais**
- C'est votre identifiant officiel à l'association

## 🆘 Dépannage

### Problème : Carte toujours verrouillée
**Solution** :
- Vérifiez que vous avez rempli **au moins 12 champs** sur les 14 requis
- Les champs optionnels (téléphone, photo) ne comptent pas
- Remplissez tous les champs marqués avec * (astérisque)

### Problème : Âge incorrect
**Solution** :
- L'âge est calculé automatiquement à partir de votre date de naissance
- Vérifiez que la date est correcte (format: JJ/MM/AAAA)
- Enregistrez à nouveau après correction

### Problème : Photo ne s'affiche pas
**Solution** :
- La photo n'est pas obligatoire (placeholder par défaut)
- Pour ajouter une photo: Cliquez sur "Compléter mon profil" → Section "📸 Photo"
- Format accepté : JPG, PNG (max 5MB)
- Réenregistrez après upload

### Problème : PDF ne s'ouvre pas
**Solution** :
- Vérifiez que votre navigateur accepte les pop-up
- Essayez d'imprimer avec un autre navigateur (Chrome, Firefox)
- Désactivez les bloqueurs de publicité temporairement
